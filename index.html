Profile / About Vito
Hello,
Vito.

Perspektif bisnis.
Kepekaan editorial.
Cerita yang bermakna.

Saya Benedictus Yurivitokris Nugroho, biasa dipanggil Vito. Latar belakang jurnalisme bisnis dan ekonomi membentuk cara saya memahami konteks, memilah informasi, dan menemukan sudut cerita.

Saya tertarik membawa pengalaman tersebut ke peluang Corporate Communication, Public Relations, Marketing Communication, Brand Communication, dan Content Strategy.

Panduan pemilik website / README

Membuka dan meninjau

Simpan file ini sebagai index.html, lalu klik dua kali untuk membuka di browser. Semua CSS, JavaScript, dan visual konseptual berada di file ini. Tidak ada build, CDN, tracking, atau layanan backend. Tautan LinkedIn membutuhkan internet. Publikasikan hanya index.html jika nanti sudah diizinkan; tahap ini belum melakukan deployment.

Mengubah isi

  • Profil: ubah teks pada hero dan bagian About, serta title dan meta description.
  • Kontak: ubah URL LinkedIn di bagian Contact. Jangan menambahkan formulir pengiriman tanpa backend.
  • Karya: ubah artikel di work-list dan artikel dengan ID project-* yang sesuai. Samakan href pada pemicu detail dengan ID detail. Template project-fields berisi kolom bersama; ganti kolom per karya dengan informasi asli sebelum publikasi.
  • Gambar: visual saat ini adalah bentuk CSS. Untuk gambar asli, ganti blok art dengan elemen img yang memiliki alt, ukuran responsif, dan path relatif. Memasukkan gambar ke folder saja tidak otomatis menampilkannya. Agar tetap satu file dan offline, gambar dapat disematkan sebagai data URI.
  • File dan folder: index.html adalah seluruh website sekaligus panduan ini; tidak ada style.css, script.js, atau folder aset terpisah sesuai permintaan satu file. Jika dipisah kelak, gunakan assets/images untuk gambar, assets/fonts untuk font beserta lisensi, assets/projects untuk materi karya, dan assets/documents untuk CV/PDF.

Materi yang perlu dilengkapi

Siapkan tangkapan website, scan koran/PDF, dan materi video sesuai daftar kategori; brief, tujuan, audiens, pesan, proses, keluaran, tahun terverifikasi, bukti hasil bila tersedia, serta tautan publikasi dan izin menampilkan materi. Tambahkan data sarjana dan SMA, periode pengalaman Kompas/SWA, serta materi semua kategori pada indeks karya.

Menambahkan screenshot dan PDF

Gunakan cuplikan untuk tampilan awal dan pertahankan halaman utuh di detail karya. Jangan mengecilkan seluruh halaman koran menjadi thumbnail yang harus dibaca. Di dalam project-media pada artikel project-* yang sesuai, tambahkan <img src="data:image/png;base64,…" alt="Deskripsi halaman dan judul karya"> dan tautan <a href="data:application/pdf;base64,…" download="karya.pdf">Unduh PDF asli</a>. Gunakan data URI untuk menjaga satu file; gambar/PDF besar akan menambah ukuran file. Ganti placeholder visual setelah materi asli tersedia, jangan hanya mengubah labelnya. Untuk video, gunakan tautan publikasi yang sah atau video beratribut controls tanpa autoplay. Tulis cuplikan teks dan konteks dalam HTML agar informasi tetap dapat diakses tanpa membaca gambar.

Font, gerakan, dan aksesibilitas

Menggunakan font sistem Arial, Helvetica, dan Georgia dengan fallback lokal. Tidak ada berkas font pihak ketiga yang didistribusikan sehingga tidak ada lisensi font tambahan. Detail karya dibuka sebagai halaman tersendiri melalui hash URL (misalnya #project-strategic-1) dalam file yang sama; tautan dapat dibagikan atau dibuka langsung. Tombol kembali browser dan tautan kembali ke galeri didukung. Tanpa JavaScript, tautan karya menuju catatan di halaman utama. Tombol jeda menghentikan gerakan berulang; preferensi reduced motion dihormati. Tanpa JavaScript, navigasi, accordion, informasi utama, dan detail dasar tetap terbaca.
